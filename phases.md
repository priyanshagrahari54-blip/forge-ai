# FORGE AI — MASTER ROADMAP
## Phase 0 — Repository Truth
Audit code, tests, CI, deployment, docs and runtime; build a gap matrix.

## Phase 1 — Foundation
Startup, config, auth, persistence, events, shutdown and API contracts.

## Phase 2 — Task Engine
Queue, immediate wake, workers, leases, concurrency, retry, cancellation, recovery and checkpoints.

## Phase 3 — Model Fabric
Registry, dynamic discovery, canonical capabilities, health, real inference verification, routing, preference/fallback chains and telemetry.

## Phase 4 — Providers
Verify each configured provider/model with bounded real probes. Isolate failures.

## Phase 5 — 1,040 Agents
Validate 40×26, capability mapping, model pools, tools, memory scopes, security and representative execution.

## Phase 6 — Supervisor
Planning, DAG decomposition, parallel execution, integration, testing, debugging, security, review, benchmark and rollback.

## Phase 7 — Tools
Filesystem, Git, terminal/code, browser, research, HTTP, database, vision, computer-use, deployment and remote compute.

## Phase 8 — Personal AI
Sessions, context, preferences, project awareness and continuity.

## Phase 9 — Memory
Short/long-term, episodic, semantic, project and operational memory; retrieval, provenance, contradictions and user controls.

## Phase 10 — Prompt Intelligence
Intent, ambiguity, requirements, constraints, decomposition, tool/agent/model selection and model-specific prompts.

## Phase 11 — Research
Search, source validation, evidence, cross-checking, contradiction detection, synthesis and citations.

## Phase 12 — Voice
STT, Hindi/Hinglish/English normalization, conversation/action classification, policy, TTS, interruption and E2E.

## Phase 13 — Vision/Computer Use
Real provider-backed visual understanding and permissioned actions.

## Phase 14 — AI City
Real event/state projection, live task/agent/model visualization and drill-down.

## Phase 15 — Evaluation/Learning
Quality metrics, failure analysis, pattern discovery, routing/prompt improvement proposals, benchmarks and rollback.

## Phase 16 — Security
Prompt injection, SSRF, command execution, secrets, path traversal, sandboxing, isolation and audit.

## Phase 17 — Performance
Measure and optimize API, queue, workers, routing, provider calls, memory and frontend.

## Phase 18 — Production Gate
CI + startup + auth + real inference + representative agents + complex task + recovery + security + voice + AI City + rollback.

## Phase 19 — Scale
Only when required: PostgreSQL, distributed queue, autoscaling, object storage and GPU infrastructure.
