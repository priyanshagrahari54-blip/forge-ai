FORGE AI — REAL PUBLIC MODEL NAME REFERENCE
============================================

Purpose
-------
This file contains concrete model names published by providers or model
registries. These names are REAL PUBLIC MODEL IDENTIFIERS, not placeholders
such as "openai:runtime-discovery".

IMPORTANT STATUS RULE
---------------------
A name in this file means the model name is publicly documented/observed.
It does NOT mean Forge currently has an API key, paid access, quota, or a
successful runtime connection to that model.

Forge runtime truth remains:

PUBLIC MODEL NAME -> configured? -> reachable? -> verified? -> LIVE

Never promote a public reference directly to LIVE.

8. HUGGING FACE / OPEN MODELS
-----------------------------
Hugging Face contains a very large and continuously changing model registry.
Forge should NOT copy the entire registry into a static file and call it live.
Instead, the Hugging Face connector should discover model IDs dynamically.

Examples of concrete public model IDs currently visible include:

- Qwen/Qwen3.5-0.8B
- Qwen/Qwen3.5-2B
- Qwen/Qwen3.5-4B

- Qwen/Qwen3.5-397B-A17B

Hugging Face also contains thousands of community fine-tunes, quantizations,
distillations and derivatives. These should be dynamically discovered and
verified before Forge marks them available.

10. RUNTIME DISCOVERY REQUIREMENT
---------------------------------
For each provider, Forge should eventually support:

- list models
- get model metadata
- capabilities/modality
- context length
- maximum output
- pricing when available
- availability
- authentication state
- quota/rate-limit state
- health check
- verification probe where safe
- deprecation state

Only after these checks should Model Fabric classify a model as configured,
reachable, verified or LIVE.

11. SOURCE POLICY
-----------------
Official provider documentation is preferred for proprietary model names.
Model registries such as Hugging Face are used for open/community model IDs.
