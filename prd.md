# FORGE AI — MASTER PRD
## Mission
Forge AI is a server-side personal AI + engineering orchestration platform. It converts natural requests into permissioned, observable and verifiable outcomes.

## Product pillars
Conversation; Personal Assistant; Sessions; Memory; Prompt Intelligence; Deep Research; 1,040 logical specialists; Model Fabric; Tools; Voice; Vision; Computer Use; AI City; Evaluation; Controlled Learning; Security; Deployment.

## Core flows
### Chat
input → context → eligible verified model → answer → optional memory proposal.
### Task
intent → policy → persistent task → scheduler → worker → specialist/model/tool → verification → result.
### Complex engineering
requirements → plan → DAG → specialist allocation → implementation → tests → debugging → security → review → benchmark → artifact.
### Research
question → scope → search → sources → evidence → contradictions → synthesis → citations.
### Voice
speech → STT → intent → policy → answer/action → TTS.

## Hard requirements
1. 1,040 logical specialists = 40×26; not 1,040 simultaneous heavyweight models.
2. Heavy compute remains server/provider-side; the G560 is a thin client.
3. Model discovery never equals inference.
4. Configured API keys never equal working provider.
5. Task QUEUED never equals completed.
6. Important outputs receive independent verification.
7. Memory is user-controlled and provenance-aware.
8. No fake AI City activity or simulated production success.

## Functional requirements
Authentication; durable sessions; persistent task queue; workers; retries; cancellation; recovery; Model Fabric; dynamic model discovery; real inference probes; capability routing; specialist fleet; multi-agent supervisor; tools; research; memory; voice; vision; computer-use; remote compute; AI City; observability; security; rollback.

## NFR
Reliability, security, measurable latency, resource efficiency, maintainability, accessibility and truthful state reporting.

## Definition of done
IMPLEMENTED + TESTED + INTEGRATED + RUNTIME-VERIFIED + SECURITY-VERIFIED + OBSERVABLE + RECOVERABLE + DOCUMENTED.
