# FORGE AI — DEEP RESEARCH SPECIFICATION
## Pipeline
Question → scope → research plan → source discovery → retrieval → source classification → evidence extraction → comparison → contradiction detection → synthesis → citations → report.

## Source quality
Prefer authoritative/primary sources for factual claims. Track publication date, retrieval time, source type and provenance.

## Evidence states
Verified, supported, conflicting, uncertain, inferred, speculative.

## Safety
Only lawful/authorized research. Never bypass authentication or access controls. Unknown/malicious files must not auto-execute.

## Research memory
Store claims/evidence with provenance so later work can retrieve and re-check rather than blindly reuse old conclusions.
