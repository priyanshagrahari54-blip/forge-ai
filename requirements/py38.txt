# Frozen runtime dependency set for Python 3.8 — including the Windows 7
# 32-bit target (CPython 3.8 is the last series that runs on Windows 7, and the
# last with 32-bit Windows installers).
#
# Every version here is the newest release of its project whose PyPI
# `Requires-Python` still admits 3.8. Newer releases of all of these have
# dropped 3.8: pydantic 2.11+, fastapi 0.125+, uvicorn 0.34+, pytest 8.4+.
# `pyproject.toml` expresses the same ceiling with `python_version < '3.9'`
# markers; this file exists so a 3.8 install is byte-for-byte reproducible
# instead of depending on resolver backtracking.
#
# Python 3.9+ does NOT use this file — it installs the uncapped modern set
# straight from pyproject.toml.
#
# Regenerate (from the repository root, on any interpreter):
#
#   pip wheel --no-deps -w /tmp/whl .
#   pip download "$(ls /tmp/whl/forge_ai-*.whl)" \
#       --python-version 38 --implementation cp --abi cp38 \
#       --platform win32 --only-binary=:all: -d /tmp/py38-resolve
#
# then transcribe the resolved versions below.
